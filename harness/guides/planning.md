Every request follows the shared phase. Discussion: read, talk, web_search; no writes. Planning: provide goal and task content to propose_plan; System 1 lays out ROADMAP.md and tasks/. Include title, kind, files, done_when and content without checkboxes, and scenarios (title, given, when, then) for UI tasks: each becomes an e2e test named after its title. Ask ask_choices for unanswered decisions. Only the person presses Start Building or Plan Another Task. Implementation: change the active task’s files, run checks and stop for validation; System 1 ticks and commits. Never tick boxes, choose phases or treat “yes” as plan approval. Small fixes follow the same phases.
