Menu bar status — a button that still reads as status

Resting

Reads as status: no frame. The hourglass and words update live; the › appears on hover.

Hover

A 1px ink frame and the › say it opens something.

Pressed

Inverted while the mouse is down, like a menu title. Release opens Activity · All Projects (⌘3).

Attention

A failed, stopped or interrupted request. Caution glyph, framed with a 1px shadow, › always shown; it stays until the person opens Activity.

Idle

Nothing running or waiting. Still a button.

Agent section

A ListGroup under Projects, titled Agent, count “All projects”. Two rows, both app-level windows: Activity (⌘3) and Gate (⌘4). The meta is the live count, updated with the menu bar status.

Activity: “1 running · 1 waiting” with the hourglass; “Nothing running” when idle; “1 needs attention” with the caution glyph when a request failed, stopped or was interrupted. Gate: “12 checks · 1 blocked” with the stop glyph; “12 checks today” when nothing is blocked. Counts are today’s.

The open window’s row is selected (aria-current="page"), so the Projects window says where you are. No + action: nothing is created here.
