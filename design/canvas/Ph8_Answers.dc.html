1 · The π sheet

Commands next to what they act on. π keeps the app-wide ones: projects (each with its ⋯), Agent, Model, New Project… / Add Existing Folder…, Settings…, About.

The view menu (Chat ▾) switches views and then holds that view’s commands: Chat’s Compact Now, New Conversation…, Earlier Conversations; Preview’s app language. ⋯ holds the commands of the thing on screen: file, folder, project.

The PhoneBar card’s “every menu command” becomes this three-place rule.

2–3 · Model, files, folders

Build Ph_Model and Ph_ModelList as drawn, with the four thinking levels (Ph8_Thinking). When the chosen model is gone, an alert line in Chat with Choose Model… (Ph8_ModelGone).

Build Ph_FileMore and Ph_FolderMore. A folder opens as a level with its own ⋯; no inline expand on the phone. The ⋯ sheet’s title is the file’s path, which answers “paths are visible nowhere”.

4–5 · Review and Ask

Comments is always in the document bar, with the open count when there is one. With none open, the sheet says so, keeps Resolved and Deleted one tap away, and holds Ask Pi About This File… (Ph8_CommentsNone).

Ask Pi… has its own sheet for a selection, a block and the whole file; only the quote line differs. The answer goes to Review beside the passage, as on the desktop; nothing becomes a comment.

6–7 · Source, Preview, Reload

View as Markdown in the file ⋯: the whole file as source, full screen, Done to go back. Not desktop-only: front matter and broken tables need it.

Stop / Start in the Preview foot, beside the state, as on the desktop; the app’s language moves to Preview’s view menu.

Reload from Disk in the file ⋯.

8–10 · Landing, status, New Project

Land on the detail. Show in Activity and Show in Gate open that request or event; the status button opens the detail when one thing needs attention, the filtered list when several. Back goes to the list.

Status on a document: keep the phone bar while reading (it hides on scroll down, returns on scroll up); only the document bar while editing. Chat is two taps from any document.

New Project: “Create in ~/code ›” as one row; the folder browser is its own full-height step (Ph8_ChooseFolder), also used by Add Existing Folder.

11–12 · Details, Files bar

Yes to all: 44 px for every listed control with the label inside the hit area; no ⌘ hints on the phone; the toast sits above the edit bar and the keyboard; Settings hides Desktop pattern and “Return sends” and says they are Mac settings.

Ph_Files, without “‹ Projects”: on the phone π is the projects list; two ways out of a project would disagree. Ph_FilesNew is corrected.
