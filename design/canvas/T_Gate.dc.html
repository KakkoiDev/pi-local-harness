Gate and recovery

A tool call is two lines: the tool and its argument, then the checks with glyph + word. Gate’s verdict and the command’s own result are separate words: “✓ Gate allowed · ✗ exit 1” replaces “Gate audit failed: EXECUTION_FAILED”, which read as if Gate had blocked it.

Only bash has an exit code; other tools read “✓ done” or “✗ failed — it failed on its own; Gate did not block it.” Blocked: nothing ran, which rule. Revise: Pi was asked to change it.

Recovery and refusal lead with a bold sentence, not a code. A loop or hang retries once by itself (“Pi asks again another way · Esc stops it”); a second failure stops with where the incident is saved. A terminal question is refused, not queued, while another request runs: the terminal answers now or says why not, rather than leaving the prompt waiting. Terminal turns have no Activity record, so no /job is offered.
