Gate and recovery

A tool call is two lines: the tool and its argument, then the checks with glyph + word. Gate’s verdict and the command’s own result are separate words: “✓ Gate allowed · ✗ exit 1” replaces “Gate audit failed: EXECUTION_FAILED”, which read as if Gate had blocked it.

Blocked: say that nothing ran and which rule. Revise: say Pi was asked to change it. Recovery and refusal messages are the harness speaking, so they lead with a bold sentence, not a code (“Harness stopped a loop.”, “Another request is running.”), then the next command.
