Workbench design

Preserve the established dark workspace and pale green accent. Use a warm charcoal canvas, a darker navigation rail, legible muted text, and restrained borders. Typography follows native application conventions with a clear title/body/metadata scale; monospace is reserved for code and paths.

Projects live in the left rail. Chat, Work, and Gate remain the main views. The active project and selected file must be clear. Search scopes to its adjacent list. Persist navigation and drafts, preserve keyboard focus during live polling, and expose conflict recovery before allowing data loss. Buttons have visible keyboard focus and touch-sized targets. Reduced motion disables transitions.
