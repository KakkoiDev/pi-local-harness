Terminal Pi — the typed member of System 1

Title bar → title rule. Every console output starts with ── Title ───, title in bold, a short summary at the right when there is one. No side borders: the output copies as clean text.

Info-bar double rule → ═══ under table headers only, as in the app.

Inversion means the same three things: the selected row in a list, the default button, and the one thing in the footer that needs you.

Glyph + word. One glyph set, every state in words beside it. Colour is never the only carrier; the 16-colour theme may tint, never inform. ASCII fallback when the terminal is not UTF-8: ok NO !! >.

Dim is secondary: times, IDs, paths, hints. Never a state.

Words: commands are typed lowercase (/status); titles and buttons are Title Case (Switch Model); an ellipsis means a question follows. Hints name the next command.

Default button: inverted, Return presses it, Esc is Cancel, and the hint line says both. Destructive changes default to Cancel.

Answers. One look for every output (title rule + indented body) with a few inner parts: key/value card, table, checklist, prose. The slash is the line: /status runs now; “status?” asks Pi, who answers from live data and puts /status on the input line. No colour carries meaning: bold, dim, inverse and underline only; links take the theme’s link colour.
