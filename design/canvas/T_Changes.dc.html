Every change shows what changes from what to what, where it is saved (model.json for the model and thinking; config.json for settings) and when it applies. The choices name the action (Switch Model, Save Setting, Remove Model).

Pi’s own select list draws the confirmation: the chosen row is marked “→” (not inverse) and Pi prints its own key hint. Order is the default: the action first, Cancel first when the change is destructive.

Pi proposes, the person runs. Pi never changes a setting. It puts the command on the input line with a dim hint; Return runs it, which still opens the confirmation.
