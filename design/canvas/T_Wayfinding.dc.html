Finding your way

/harness opens a select list, “Ask in words” first: the person should never have to remember a command to get help. Return puts the chosen command on the input line (not runs it), so arguments can be added. /harness list prints the same list as text for copying.

Completion for model names, config keys (with the current value) and guide topics, with the same glyph + word as the outputs.

Pi points, not lists. When asked “what can you do?”, Pi answers in two lines and says “type /harness”, instead of listing commands in prose.
