Adding and removing blocks

1

The handle appears when the pointer is anywhere in the 48 px gutter or on the block. Its menu: Turn Into ▸, Add Block Below, Move Up/Down, Comment on Type, Ask Pi About Type…, Delete Type. Items name the block’s type: Task, Heading, Bullet, Quote, Code. “Paragraph” is only the plain type.

2

Return at the end of a block starts a new Paragraph below it, with the placeholder “Write, or choose a style in the ruler”. Return in the middle splits the block. The Enter that confirms Japanese input never splits.

3

Lists continue: Return in a bullet, number or task makes another of the same type; numbers count 1., 2. within a run. Return on an empty list item turns it into a Paragraph. Backspace in an empty block removes it and puts the caret at the end of the block above.

4

A click on the empty page below the last block adds a Paragraph there (or focuses the last block if it is already an empty Paragraph).

Deleting a block from its menu shows a toast, “Task deleted.”, with Undo ⌘Z, for 8 seconds. Types look like themselves: quote italic in a dotted frame, code mono in an ink frame, bullets “•”, numbers “1.”, tasks a checkbox.
