# DocumentBlock

A block in the Markdown editor: text, heading, task checkbox, bullet, number, quote, code or raw Markdown, in `.pw-doc` (700px column, Source Serif 18/1.6).

- The focused block shows a dotted outline and a handle (`.pw-block__handle`, the `handle` icon) in the left gutter. The handle opens the block menu: Turn Into (types), Move Up, Move Down, Comment on Paragraph, Ask Pi About Paragraph…, Delete Paragraph.
- On phone the handle is always visible for the focused block and 44px tall.
- Markdown source mode replaces blocks with one `.pw-source` textarea (mono).
