# AttachmentChip

A file waiting in the composer: optional 22px thumbnail, the name (ellipsized at 260px), and a remove button with `aria-label="Remove <name>"`.

## Round 15: pictures Pi made are not attachments

An image or icon Pi chose or generated shows as a **VisualResult** card in Pi's message, not as an attachment chip. The chip stays for files the person attaches. A chip for an image the person attached opens the same inspector (backdrop, zoom, facts) read-only, with no Use action.
