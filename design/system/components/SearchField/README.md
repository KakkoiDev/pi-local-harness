# SearchField

A search box scoped to the list right below it (projects or files): a magnifier, the input, and the shortcut.

- `<label class="pw-search">` wrapping the icon, `<input type="search" aria-label="Find a project">` and `<kbd class="pw-kbd">⌘K</kbd>`.
- Filters as you type; an empty result shows `.pw-empty` text (No matching projects).
