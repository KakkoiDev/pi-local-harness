# TextField

Single- and multi-line text entry: `.pw-field` on `<input>` or `<textarea>`, square, 1px ink border with a 1px inner top-left edge.

- Text is the content face (Source Serif 4) because what you type is content. Placeholder is `ink-disabled`.
- Always paired with a visible `<label class="pw-label">` (the phone composer may use `.pw-sr-only`).
- The composer textarea grows to 180px, then scrolls.
