# Run on its own, and its report (AwayCard)

**Run on its own** (Auto-accept, plan 236, brief v2): Pi answers every question with the recommended option, approves its own plans, continues after every task, and also publishes, git pushes, downloads, sends messages and issues, and moves files to the Trash, without asking. Nothing is held back. Boards: R10_AutoOn, R10_AgentMenu, R10_Away, Ph10_Away, R9_Settings, Ph8_Settings, T_PlanMode.

- **One setting for all projects**, remembered, no time or task limit: Settings › Pi › Run on its own. Quick toggles of the same setting: the `label.pw-auto` checkbox beside Send (desk and phone) and Agent › Run on Its Own ⌥⌘A. Terminal: `/auto on|off`, `/config set auto`.
- **Turning it on shows the risks first, every time**, wherever it is turned on: a Caution alert “Turn on Run on Its Own?” — “For every project, until you turn it off, Pi will do all of this without asking:” then the list (publish, git push, download, send, move files to the Trash in bold) and “What leaves this Mac (a publish, a push, a message) can’t be taken back by Undo. Every step goes into a report at the end of the run.” **Turn On** · **Cancel** (default).
- **While on**: the status reads “Working · on its own”; the checkbox stays checked; the terminal footer says Auto.
- **The report** (`section.pw-card`, clock glyph) ends every run and shows again when the person comes back, if not yet seen: “Ran on its own: report · 14:40 – 16:05 · roadmap done”. Sections, each with its count: **Done** (✓ verified / ! not verified, with why), **Decided on its own** (dotted auto tag, Change… each), **Left this Mac or used the Trash** (what, where, when; Open or Show), **Problems** (failed tests, Gate blocks, retries). Foot: **Got It** (default) · Show in Activity. Terminal prints a one-line summary; `/report` prints it in full.
