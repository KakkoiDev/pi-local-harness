# DesktopPattern

The ground behind every window: paper with a 1px ink dot every 4px. Apply `.pw-desk` to the element below the menu bar.

- Variants: `.pw-desk--gray` (50% dither) and `.pw-desk--plain`, chosen by the person under π › Desktop Pattern…; store the choice per browser.
- `.pw-dither` is the 50% pattern for scroll tracks; `.pw-scrim` dims the page behind a sheet.
- Never put text directly on the pattern: text sits in a window, menu or sheet.
