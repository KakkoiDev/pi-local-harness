# Local agent project workbench

One person works with one local agent on this machine. Projects are real folders anywhere; each has one persistent chat, roadmap, tasks, files, and actionable comments. The workbench makes current work visible and prevents lost edits or mixed project context. It runs locally, loads audio transcription only on demand, and shares a deterministic Laya gate with terminal Pi. Familiar desktop and mobile controls matter more than decorative effects. No remote identity, team collaboration, or simulated agent activity.
