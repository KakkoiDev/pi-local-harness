# LittleJS for Pi (the card)

The kit's LittleJS is **1.27.0** (`kit/vendor/littlejs-1.27.0/littlejs.esm.min.js`, types in `littlejs.d.ts`), the
engine the Kakkoi School handbook uses for browser games. For game guidance follow LittleJS-AI
(https://github.com/KilledByAPixel/LittleJS-AI), as the handbook does; the kit does not keep a second LittleJS guide.
For multiplayer, use p2p-core (its card: `kit/vendor/p2p-core-0.1.0/AGENTS.md`).
